# EfficientNet-B4 Celeb-DF 연구 모델 카드

- 상태: 연구용 기준선, 운영 미승인
- 입력: 정렬 얼굴 RGB 380×380
- 출력: fake logit; sigmoid 적용값이 딥페이크 점수
- 선택 프레임: 16
- 점수 통합: mean
- 연구 기준값: 0.7519882693886758
- 공식 Test Video ROC-AUC: 0.9998017184401851
- 공식 Test 실제영상 FPR: 0.016853932584269662
- 공식 Test 딥페이크 Recall: 1.0
- 공식 Test 커버리지: 1.0
- Gate 통과: False

이 모델은 Celeb-DF와 비상업 연구 조건의 InsightFace 얼굴 검출 전처리를 사용했다. 한국인·최신 생성 방식·실제 웹 검색 영상에 대한 운영 성능과 상용 사용권을 증명하지 않는다. 사람 검토 없이 차단·삭제를 자동 실행하지 않는다.
