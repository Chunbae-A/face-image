## 라벨 안전장치

Celeb-DF 공식 목록은 `1=실제`, `0=가짜`로 적혀 있다. 딥소각 모델 내부 규칙은 `0=실제`, `1=딥페이크`다.

코드는 공식 값을 내부 값으로 변환한 뒤 파일 경로의 종류와 다시 대조한다. 예를 들어 `Celeb-real` 경로가 공식 목록에서 가짜로 표시되면 학습하지 않고 오류로 중단한다. 이 검사는 단위 테스트로 고정했다.

## 분할 결과

프레임을 뽑기 전에 영상을 먼저 분할했다.

| Split | 전체 | 실제 | 딥페이크 | 사용 목적 |
|---|---:|---:|---:|---|
| Train | 5,175 | 604 | 4,571 | 모델 가중치 학습 |
| Validation | 836 | 108 | 728 | 프레임 수·통합 방식·기준값 선택 |
| 공식 Test | 518 | 178 | 340 | 선택 완료 후 최종 성능 확인 |

학습 시에는 실제·가짜 개수 차이를 그대로 두지 않고 역빈도 균형 샘플링을 적용한다.

## 누수 검사

| 검사 | 결과 |
|---|---:|
| Train/Validation 동일 영상 교집합 | 0 |
| Train/Validation 원본 대상 인물 그룹 교집합 | 0 |
| Train/Validation 합성 기증 인물 교집합 관측값 | 53 |
| Train/Test 동일 영상 교집합 | 0 |
| Validation/Test 동일 영상 교집합 | 0 |
| 공식 Test가 Test 밖으로 빠져나간 수 | 0 |

`id0_id16_0000`은 id0의 원본 영상에 id16의 얼굴을 합성했다는 뜻이다. 내부 분할은 첫 번째 원본 대상 ID를 묶어 동일 대상 영상 맥락이 섞이지 않게 했다. 두 번째 기증 ID는 여러 대상 조합에 반복되므로 Train/Validation에서 53개가 겹치며 이를 한계로 기록한다.

공식 Test는 데이터셋 제작자가 미리 정한 벤치마크다. 이 목록의 원본 대상 인물 그룹은 Train과 46개, Validation과 8개가 겹친다. 이는 동일 영상을 섞은 누수가 아니라 공식 분할의 특성이다. 결과 해석에서는 “모든 인물이 처음 등장하는 완전 분리 테스트”라고 표현하지 않는다.
