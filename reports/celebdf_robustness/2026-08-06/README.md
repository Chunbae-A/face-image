# 얼굴가드 촬영 열화 6조건 평가 — 2026-08-06

## 한 줄 결론

흐림·저조도·압축 같은 열화에서도 같은 사람을 놓치는 문제는 관측되지 않았고 처리 성공률도 높았다. 하지만 **다른 사람을 같은 사람으로 잘못 받아들이는 비율(FAR)이 목표를 넘었기 때문에, 이번 결과로 API 판정 기준값을 운영값으로 바꾸지 않는다.**

이 실험은 기존 ArcFace 기준선을 나쁜 촬영 조건에서 검사한 것이다. 새 신경망을 학습하거나 품질 가중 평균을 적용한 모델 고도화 실험은 아니다.

## 무엇을 시험했나

- 실행 환경: Kaggle 비공개 Notebook, Tesla P100 16GB
- 데이터: 정식 승인을 받은 Celeb-DF-v2의 `Celeb-real` 590개 영상, 59명
- 평가 가능 인물: 영상 8개 이상인 56명
- 모델: InsightFace `buffalo_l`, 512차원 ArcFace 특징
- 런타임: `onnxruntime-gpu==1.23.2`, CUDAExecutionProvider
- 프레임: 영상당 5개
- 등록: 인물당 깨끗한 등록 영상 3개를 단순 평균
- 확인 영상: 인물별 6번째 영상부터 사용하며, 여섯 조건에서 모두 성공한 동일한 291개 영상으로 비교
- 반복: 인물이 겹치지 않는 Validation/Test 분할 5회
- 판정 기준 선택: Validation 인물만 사용하고 Test 인물에는 고정
- 최대 추론량: `590영상 × 5프레임 × 6조건 = 17,700프레임`

등록 얼굴은 깨끗한 상태로 유지하고 확인 얼굴에만 다음 변환을 적용했다.

1. 원본에 가까운 깨끗한 영상
2. JPEG 품질 30 압축
3. 가우시안 흐림 sigma 2
4. gamma 2.0 저조도
5. 가로·세로 25% 축소 후 복원
6. 저해상도·저조도·압축 복합 열화

## 결과

`clean 고정 FAR`은 깨끗한 Validation에서 정한 하나의 기준값을 모든 조건에 사용한 결과다. `조건별 보정 FAR`은 각 열화 Validation에서 기준값을 다시 정한 결과다. 목표 FAR `0.001`은 타인 비교 1,000번당 오수락 약 1번 수준을 뜻한다.

| 확인 얼굴 조건 | 정상 처리 | TAR | clean 고정 FAR | 조건별 보정 FAR |
|---|---:|---:|---:|---:|
| 깨끗한 영상 | 589/590 (99.83%) | 1.000000 | 0.001380 | 0.001380 |
| JPEG 압축 | 589/590 (99.83%) | 1.000000 | **0.001609** | **0.002091** |
| 가우시안 흐림 | 589/590 (99.83%) | 1.000000 | 0.001433 | 0.001840 |
| 저조도 | 589/590 (99.83%) | 1.000000 | 0.001226 | 0.000822 |
| 해상도 축소 | 589/590 (99.83%) | 1.000000 | 0.001560 | 0.001716 |
| 복합 모바일 열화 | 589/590 (99.83%) | 1.000000 | 0.001408 | 0.001439 |

모든 조건의 Test ROC-AUC 평균은 `1.000000`, EER 평균은 `0.000000`이었다. clean 고정 기준의 TAR도 모두 `1.000000`이어서 깨끗한 조건 대비 TAR 손실은 `0.0%p`였다.

그러나 깨끗한 조건부터 FAR 평균이 `0.001380`으로 목표를 넘었다. 최악 조건인 JPEG 압축은 clean 고정 FAR `0.001609`, 조건별 보정 FAR `0.002091`이었다. 즉 타인 비교 1,000번당 목표가 약 1번인데, 최악 평균은 각각 약 1.61번과 2.09번 수준이었다. 조건별 보정도 전체 조건의 문제를 해결하지 못했다.

## 판정 Gate

| 검사 항목 | 기준 | 결과 | 판정 |
|---|---:|---:|---|
| 처리 성공률 | 98% 이상 | 모든 조건 99.83% | 통과 |
| TAR 손실 | 깨끗한 조건 대비 5%p 이하 | 모든 조건 0.0%p | 통과 |
| 단일 기준값 FAR | 최악 평균 0.001 이하 | 0.001609 | **실패** |
| 조건별 보정 FAR | 최악 평균 0.001 이하 | 0.002091 | **실패** |
| 데이터 누수 | 모든 교집합 0 | 5개 seed 모두 0 | 통과 |

처리 성공률과 TAR만 보면 이번 합성 열화에 대한 별도 재촬영 차단 조건은 발견되지 않았다. 다만 FAR Gate가 실패했으므로 이를 “운영에 안전하다”는 뜻으로 해석하면 안 된다.

## API 적용 결정

- API의 판정 기준값은 **변경하지 않는다**.
- `threshold_status=research_only_unapproved`를 유지한다.
- `is_same_person=true`는 데모에서 “같은 사람 후보”로만 사용한다.
- 이 값만으로 계정 복구·삭제 같은 되돌리기 어려운 작업을 자동 승인하지 않는다.
- 저조도 한 조건의 보정 평균만 목표를 통과했지만, 전체 조건 운영 기준으로 채택하지 않는다.

이번 실험으로 확인한 핵심 문제는 촬영 열화 때문에 같은 사람을 놓치는 현상보다 **기존 데이터에서 FAR 목표를 안정적으로 추정하고 지키지 못하는 것**이다. 다음 모델링 우선순위는 더 큰 모델로 교체하는 것이 아니라 Validation 표본 확대, 판정 기준 보정 방식 개선, 품질 기반 거절 또는 품질 가중 등록 방식의 독립 비교다.
