# 얼굴가드 로컬 데모 스모크 결과 — 2026-08-06

## 결론

Docker로 실행한 얼굴가드 API가 **등록 사진 3장과 같은 사람 확인 사진 1장은 일치 후보로, 다른 사람 확인 사진 1장은 불일치로 반환**했다. 첫 모델 준비 후 CPU 요청은 이번 두 건에서 약 0.96~1.19초가 관측됐다.

판정은 다음과 같다.

- 로컬 데모 기능 연결: **통과**
- 운영 정확도·본인인증 안전성: **미승인**
- 판정 기준 상태: `research_only_unapproved`

이 결과는 API가 끝까지 동작하는지 확인한 기능 스모크다. 정확도, 오인식률, 한국인 일반화, 실제 휴대전화 촬영 성능 또는 운영 SLA를 증명하지 않는다.

## 시험 범위

- 정식 사용 승인을 받은 `Celeb-DF-v2/Celeb-real` 사용
- 같은 인물의 서로 다른 영상에서 등록용 전체 프레임 3장과 확인용 전체 프레임 1장 선택
- 다른 인물의 별도 영상에서 불일치 확인용 전체 프레임 1장 선택
- 사진마다 얼굴이 정확히 한 명 탐지되는지 로컬에서 먼저 확인
- 동일한 Docker API에 첫 요청, 예열 후 같은 사람 요청, 예열 후 다른 사람 요청 순서로 실행

원본 영상, 추출 프레임, 얼굴 crop, 인물·영상 ID, 파일명, 임베딩과 사람별 품질값은 GitHub 결과에 포함하지 않았다.

## 데이터 보호 확인

- 원본 ZIP과 영상은 승인된 로컬 경로에서만 읽었다.
- 데모용 전체 프레임은 Git에서 제외되는 `data/interim`에만 만들었다.
- 인벤토리와 선택 정보는 Git에서 제외되는 `data/metadata`에만 두었다.
- API 응답과 이 보고서에는 원본 사진, crop, 임베딩과 파일명을 넣지 않았다.
- 커밋 전 Git 변경사항에 데이터 파일이 포함되지 않았는지 검사한다.

## 데모 운영 결정

1. 발표 전에 동의받은 샘플로 한 번 요청해 `model_loaded=true`를 만든다.
2. 화면에는 “같은 사람 후보”라고 표시하고 운영 본인인증 성공이라고 표현하지 않는다.
3. `is_same_person=true`만으로 삭제·복구 같은 동작을 자동 실행하지 않는다.
4. 첫 모델 준비시간과 예열 후 처리시간을 구분해 설명한다.
5. 다음 단계에서 `/demo` 화면과 오류·재촬영 상태를 연결한다.
6. Kaggle 열화 평가와 외부 실제 촬영 검증 후 판정 기준을 다시 검토한다.

기계 판독 가능한 동일 결과는 [`faceguard_demo_smoke.json`](faceguard_demo_smoke.json)에 있다.
