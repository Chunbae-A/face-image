# K-FACE 저화질·중화질 얼굴 특징 안정성 파일럿

## 한 줄 결론

승인받은 K-FACE 원본을 GitHub나 외부 GPU에 올리지 않고 로컬에서 저화질과
중화질을 분리 처리했다. 같은 30명·450장을 비교했을 때 중화질의 얼굴 특징 추출
성공률은 **88.67%**로, 저화질 **78.44%**보다 **10.22%p 높았다.**

이 실험은 **딥페이크 판별 모델 학습이 아니라**, 공개 후보에서 등록자와 같은 얼굴을
선별하는 ArcFace 단계가 한국인 얼굴의 화질 변화에 얼마나 안정적인지 확인하는
파일럿이다.

## 고정한 실험 조건

| 항목 | 설정 |
|---|---|
| 데이터 | AI-Hub 승인을 받아 내려받은 K-FACE 저화질·중화질 |
| 저화질 ZIP 확인 | 400명, 인물별 ZIP 안에 10,800장 |
| 파일럿 표본 | 내부 ZIP 이름 정렬 기준 앞 30명 |
| 표본 일치 검사 | 저·중화질 30명 모두 이미지 멤버 목록 일치 |
| 인물별 입력 | 전체 목록에서 균등 간격으로 선택한 15장 |
| 얼굴 검출 | InsightFace `buffalo_l`의 SCRFD |
| 얼굴 특징 | ArcFace 512차원 임베딩 |
| 실행 환경 | Apple Silicon Mac, ONNX Runtime CPU |
| 원본 처리 | 인물별 ZIP 하나만 메모리에서 읽고 얼굴 이미지는 저장하지 않음 |
| 재시작 | 인물별 완료 체크포인트로 이미 끝난 인물은 건너뜀 |

중화질 전체 다운로드가 오래 걸려, 다운로드 파일 앞부분에서 완전히 수신된 인물별
ZIP 중 저화질 표본과 이름이 일치하는 30개만 골랐다. 각 내부 ZIP은 원본 헤더의
크기와 CRC-32를 통과한 경우에만 별도 비공개 파일럿 ZIP에 포함했다. 불완전한 인물
파일이나 서로 다른 인물 표본은 비교에 들어가지 않았다.

저화질과 중화질에서 같은 인물 순서와 같은 이미지 선택 규칙을 사용한다. 파일럿은
전체 400명의 운영 성능을 확정하는 평가가 아니며, 다음 실험의 가능성과 병목을 빠르게
확인하기 위한 표본이다.

## 저화질 확정 결과

| 지표 | 결과 |
|---|---:|
| 선택한 인물 | 30명 |
| 시도한 이미지 | 450장 |
| 얼굴 특징 추출 성공 | 353장 |
| 얼굴 특징 추출 실패 | 97장 |
| 얼굴 특징 추출 성공률 | **78.44%** |
| 얼굴 미검출 | 53장 |
| 검출 신뢰도 미달 | 44장 |
| 처리 시간 | 84.49초 |

저화질에서는 약 5장 중 1장이 얼굴 선별 단계에서 제외됐다. 이는 “다른 사람으로
오판했다”는 뜻이 아니라, 입력 품질이 현재 검출 기준을 통과하지 못해 비교 자체를
수행하지 않았다는 뜻이다.

## 중화질 확정 결과

| 지표 | 결과 |
|---|---:|
| 선택한 인물 | 30명 |
| 시도한 이미지 | 450장 |
| 얼굴 특징 추출 성공 | 399장 |
| 얼굴 특징 추출 실패 | 51장 |
| 얼굴 특징 추출 성공률 | **88.67%** |
| 얼굴 미검출 | 28장 |
| 검출 신뢰도 미달 | 23장 |
| 처리 시간 | 99.95초 |

## 저화질·중화질 비교

| 지표 | 저화질 | 중화질 | 해석 |
|---|---:|---:|---|
| 얼굴 특징 추출 성공률 | 78.44% | **88.67%** | 중화질이 **10.22%p 개선** |
| 실패 이미지 | 97장 | **51장** | 46장 감소, **47.42% 감소** |
| 동일인 내부 유사도 평균 | 0.5953 | **0.6506** | 중화질 특징이 인물별로 더 안정적으로 모임 |

저화질과 중화질에서 만든 같은 사람의 중심 특징을 직접 비교한 코사인 유사도는
평균 **0.9071**, 중앙값 **0.9100**, 하위 5% **0.8582**였다. 이 값은 두 화질의
얼굴 특징 방향이 대체로 일관됐다는 뜻이며, 보정된 확률이나 서비스 신뢰도는 아니다.

중화질 입력 크기는 평균 346×230, 저화질은 173×115로 정확히 두 배였다. 원본
크기에 민감한 Laplacian 분산값은 화질 간 절대 비교 지표로 해석하지 않았다.

## 결론과 적용 범위

- 중화질은 현재 SCRFD 얼굴 검출 게이트의 탈락을 실질적으로 줄였다.
- ArcFace 특징은 저화질과 중화질 사이에서도 동일인 기준으로 높은 일관성을 보였다.
- 웹 검색 후보에 중화질 원본이 있으면 우선 사용하고, 저화질만 있으면 분석 불가
  비율이 더 높다는 안내가 필요하다.
- 이 파일럿에는 다른 사람과의 오통과 비교가 없으므로 FAR·TAR 기준값은 바꾸지 않는다.
- 통제된 K-FACE 환경의 첫 30명 결과이므로 전체 한국인, 웹 재압축 이미지, 실제
  딥페이크 탐지 성능을 보장하지 않는다.

## 개인정보와 라이선스 처리

- 원본 ZIP, 얼굴 이미지, 개인별 임베딩은 GitHub에 올리지 않는다.
- 원본 경로와 실제 인물 식별자는 결과에 기록하지 않는다.
- 개인별 결과는 비공개 `data/`에만 저장하고 공개 보고서는 집계 수치만 포함한다.
- InsightFace 제공 사전학습 가중치는 비상업 연구 조건에서만 사용한다.
- 현재 결과는 연구용 파일럿이며 서비스 운영 승인이나 정확도 보증이 아니다.
